# Boss pool and boss mechanics

## Goal

Roll each layer's boss from a pool of three on the map stream, show it on the layer map, roll all twelve in endless mode, and add the engine the new bosses need: field changes (rising water, falling sections, darkness), linked units, mind control of mercs, copying a merc's skill.
